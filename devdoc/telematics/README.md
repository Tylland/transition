# Telematics TSI — Technical Documents

Official ERA Telematics Technical Specifications for Interoperability (TSI),
published by the European Union Agency for Railways.

> **Latest release:** [`V4.0.0`](https://gitlab.com/era-europa-eu/public/era-telematics-tsi/TSI_Telematics/-/releases/V4.0.0) — 2026-04-28

## Download

The recommended way to download a specific version is the
**[Releases page](https://gitlab.com/era-europa-eu/public/era-telematics-tsi/TSI_Telematics/-/releases)** — every release is
tagged with the full PDF + schema bundle attached as assets.

## What's in this repo

- 📄 **PDF Technical Documents** under `pdf/` — see [CATALOG.md](./CATALOG.md)
- 📐 **XSD schemas** under `TD_105_xsd/`, `TD_B5_A2_xsd/`
- 📐 **ASN.1 schemas** under `TD_B12_asn1/`
- 📐 **JSON schemas** under `TD_B14_json/`, `TD_B5_B1_json/`
